# Crime Reporting and Tracking System 🕵️‍♀️

This is a simple, user-friendly **Crime Reporting and Tracking System** built using Python and Tkinter. It allows users to report crimes and view submitted crime records in a structured format.

---

## 📂 Features

- Submit a new crime report with title, description, date, and location.
- View all previously submitted crime reports.
- Data is stored in a **SQLite database**.
- Clean and visually styled GUI using **Tkinter**.
- Modular code structure using separate files.

---

## 🛠 Technologies Used

- Python 3.x
- Tkinter (for GUI)
- SQLite (for local database)
- Git & GitHub (for version control)
